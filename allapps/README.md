## Topic Research
AI interfaces are increasingly used to make software more conversational, adaptive and insight-driven. Common patterns include chat assistants, prompt builders, summaries and AI-generated recommendations. Modern interfaces focus on clear hierarchy, minimal friction, confidence/context indicators and actionable outputs.

## Implemented UIs
1. **AI Chat** — conversational assistant with responsive message composer.
2. **AI Prompt Interface** — prompt workspace with suggestions, live preview and metrics.
3. **AI Summary Card** — compact AI summary with takeaways and next actions.
4. **AI Insight Card** — AI-generated analytics insights with confidence indicators.
