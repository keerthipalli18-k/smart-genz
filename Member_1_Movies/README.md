# Member 1 Movies
## Hackathon Topic
**Entertainment & Booking UI Templates**

### Team structure
This package contains 4 app templates. Each app has four pages, and every page contains:
- `index.html`
- `style.css`
- `javascript.js`

### Subtopic
Movies

### Apps
- Movie Ticket Booking
- Cinema Seat Booking
- Movie Discovery
- Movie Premiere Events

### How to run
Open any app's `home/index.html` in a modern browser. Use the navigation links to move between pages.

### Technologies
HTML5, CSS3, JavaScript (no external dependency required).
