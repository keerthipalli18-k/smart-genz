# Health Analytics Dashboard

## What is the UI pattern?
A personal health analytics dashboard that combines metrics, charts, goals, and insights.

## Where is it used?
Fitness apps, digital health platforms, wellness trackers, and patient portals.

## Why is it relevant?
Modern health interfaces need to turn multiple data points into understandable visual summaries.

## Design patterns observed
Metric cards, trend charts, score rings, goal indicators, filters, and AI insight panels.

## What this implementation adds
A responsive dashboard with simulated activity data and an interactive AI insight card.

## Run
Open `index.html` in a modern browser.
