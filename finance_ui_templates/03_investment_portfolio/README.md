# Investment Portfolio

## Research
**What is this UI pattern?**  
A portfolio interface presents holdings, allocation, performance and watchlist information so investors can monitor investments without navigating several separate screens.

**Where is it used?**  
Modern fintech products, personal finance platforms, banking applications, investment tools, and financial planning services.

**Why is it relevant?**  
Finance interfaces increasingly prioritize clarity, responsive layouts, real-time feedback, progressive disclosure, and actionable data rather than dense tables alone.

**Patterns observed**
- Card-based information hierarchy
- Strong typography for financial totals
- Responsive grid layouts
- Status colors for positive/negative changes
- Interactive controls and lightweight feedback
- Mobile-friendly data presentation

**What this implementation adds**
This template is an original HTML/CSS/JavaScript implementation designed as a reusable starting point rather than a copy of an existing product. It emphasizes a focused workflow, responsive behavior, and small interactive demo states.

## Features
- Responsive design
- HTML, CSS and vanilla JavaScript
- Interactive controls
- No external dependencies
- Modern dark/light visual system
- Accessible semantic structure

Open `index.html` directly in a modern browser, or use VS Code Live Server.
