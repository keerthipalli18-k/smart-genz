# Doctor Appointment & Telehealth

## What is the UI pattern?
A healthcare discovery and appointment-booking interface with telehealth actions.

## Where is it used?
Doctor directories, hospital portals, telemedicine platforms, and patient apps.

## Why is it relevant?
Users expect healthcare access to be searchable, convenient, and increasingly digital.

## Design patterns observed
Search and filters, specialist cards, time-slot chips, recommendation labels, and prominent appointment actions.

## What this implementation adds
Specialty/search filtering, simulated appointment booking, and a telehealth consultation CTA.

## Run
Open `index.html` in a modern browser.
