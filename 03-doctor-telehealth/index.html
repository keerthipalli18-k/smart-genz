UI Template Collection Hackathon GitHub Team Collaboration 📌 Project Overview In this project, you will work in teams to build a Web UI Template Collection while learning and practicing a real-world GitHub collaboration workflow. The project has two main objectives: Learn GitHub collaboration using Fork, Branch, Commit, Pull Request, Code Review, and Merge. Build a collection of modern and emerging UI templates based on current web design and development trends. 👥 Team Formation Create a team of 3–5 members. Each team will be assigned or select a UI topics. Each team member should make meaningful contributions to the project. Decide team roles such as UI developer, reviewer, tester, and team coordinator. 🎯 UI Topic Your team should work on a specific UI topic. Examples: Recommended project categories 1. Clone your fork locally. Create a separate branch for your work. Implement your UI contribution Commit your changes with a meaningful commit message. Push your branch to your fork. Create a Pull Request. Review the Pull Request of another team member. Make changes if requested. Merge the approved Pull Request. Do not directly make all changes to the main branch. 💻 Technical Requirements Each UI contribution should: Use HTML, CSS, and JavaScript. Be responsive. Work correctly in a modern browser. Have clean and readable code. Use meaningful file and class names. Include appropriate documentation. Avoid unnecessary dependencies. Use original implementations rather than copying an existing website. Recommended structure: your-ui/ ├── index.html ├── style.css ├── script.js └── README.md 🔎 Research Requirement Before developing your UI, briefly research the selected topic. Your README should mention: What the UI pattern is. Where it is commonly used. Why it is relevant to modern web interfaces. What design/interaction patterns you observed. What your implementation does differently or adds. The goal is to study existing UI patterns and create your own implementation, not to copy another website. 📦 Team Deliverables Each team should submit: GitHub Repository The repository should contain all completed UI implementations. Pull Requests Each team member should have meaningful GitHub contributions through Pull Requests. README The README should contain: Team name Team members Selected UI topic Topic research List of implemented UIs Technologies used Screenshots/previews Instructions for running the project Final Demonstration Each team should demonstrate: The UI templates created GitHub workflow used Individual contributions Pull Requests and reviews Final working result ⭐ Important This project is not only about creating UI designs. You are expected to demonstrate both: UI Development + GitHub Collaboration Your GitHub contribution history, branches, commits, Pull Requests, and code reviews are part of the learning outcome. 🚀 Goal By the end of this project, we aim to create a growing community-driven collection of modern web UI templates while giving every participant practical experience with collaborative software development.
