Explain recursion simply

ContextComputer Science · Recursion
✦
LearnAI

Think of recursion like a set of boxes inside boxes. A function solves a small part of a problem, then asks itself to solve the smaller version until it reaches a simple case.

function countdown(n) {
  if (n === 0) return;
  console.log(n);
  countdown(n - 1);
}
