# AI Patient Health Risk Dashboard

## What is the UI pattern?
An explainable AI interface for patient risk monitoring.

## Purpose
This is a responsive educational UI template for the Health sector.

## Design approach
The interface uses modern cards, clear hierarchy, responsive layouts, interactive controls, and health-focused visual patterns.

## Run
Open `index.html` in a modern browser.

## Note
This is a UI demo and does not provide medical diagnosis or clinical advice.
